# Count4U

Count4U is a web-based stock and sales management system designed to help spaza shop owners manage their products, track stock, and record customer sales more easily.

## Features

- **Product Management:** Add and manage products and categories.
- **Sales Recording:** Select products and calculate purchase totals.
- **Stock Management:** Update stock when products are sold or restocked.
- **Low-Stock Alerts:** Identify products that need restocking.
- **Sales Information:** View daily sales and product performance.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Purpose

Count4U aims to simplify stock management and sales tracking for small spaza shops, helping owners make better decisions about their products.
